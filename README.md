MacroClicker — профессиональный автокликер с привязкой к окну



**MacroClicker** — мощная программа для автоматизации кликов мыши и других действий. Поддерживает привязку к окну, запись макросов, ручной ввод координат, скриншоты, звук, расписание и многое другое.

## 📖 Инструкция

### Привязка к окну (важно!)

Чтобы клики не сбивались при перемещении окна:

1. Перейди на вкладку **«Привязка к окну»**
2. Нажми **«Выбрать окно (5 сек)»**
3. Быстро переключись на целевое окно (браузер, игру, калькулятор)
4. Наведи мышь на это окно и подожди 5 секунд
5. Программа подтвердит выбор окна

Теперь все записанные координаты будут привязаны к этому окну.

### Запись макроса

1. Нажми `F8` — начнётся запись
2. Выполни нужные действия (клики, ввод текста, скролл)
3. Нажми `F8` снова — запись остановится

### Запуск макроса

- Нажми `F6` — макрос запустится
- Нажми `F7` — остановка в любой момент

### Настройки антидетекта

Рекомендуемые настройки для работы с сайтами:

| Параметр | Значение | Зачем |
|----------|----------|-------|
| Случайное смещение | 5-10 пикселей | Чтобы не кликать в одну точку |
| Случайная задержка | 0.5–1.5 сек | Естественное поведение |
| Случайная микро-задержка | 0.3 сек | Дополнительная рандомизация |
| Случайные пропуски (5%) | Включить | Имитация отвлечения |

## 📥 Установка

### Для пользователей (без Python)
Просто скачай `MacroClicker.exe` и запусти.

### Для разработчиков (с Python)

```bash
git clone 
cd macroclicker
pip install -r requirements.txt
python macroclicker.py
```

## 🔧 Сборка из исходников

```bash
# Установка зависимостей
pip install -r requirements.txt

# Сборка EXE
pyinstaller --onefile --windowed --name "MacroClicker" macroclicker.py
```

Готовый EXE появится в папке `dist/`

 ⚠️ Антивирусы

Некоторые антивирусы могут ложно срабатывать на программу, так как она автоматизирует действия мыши. **Это ложная тревога.**

Программа:
- Не содержит вирусов
- Не собирает личные данные
- Не отправляет ничего в интернет
- Не изменяет системные файлы

**Решение:** Добавьте `MacroClicker.exe` в исключения антивируса.

 🐛 Известные проблемы и решения

| Проблема | Решение |
|----------|---------|
| Клики не срабатывают | Запусти программу от имени администратора |
| F6/F7/F8 не работают | Проверь, не заняты ли эти клавиши другими программами |
| Окно не выбирается | Обнови список окон на вкладке «Привязка к окну» |
| Скриншоты не сохраняются | Создай папку `screenshots/` вручную |
| Ошибка кодировки в логе | Лог сохраняется в UTF-8, открой в любом редакторе |
